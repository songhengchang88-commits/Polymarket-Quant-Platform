## 🎯 核心定位与爆火底层逻辑

1. **去神圣化与“平视同理”**：
   - 彻底打破传统历史讲大道理的说教感，将历史圣贤与英雄降维为“吃过大亏、吃过苦头”的普通人（杜甫聊租房窘迫、诸葛亮聊54岁累死在案头、刘邦聊底层混混难堪、项羽聊全盘皆输的悔恨）。
   - 核心立场不是“教你如何成功”，而是“我懂你的委屈”，形成与当代年轻人的“病友/战友”共情。

2. **古典 IP 的“现代打工人语言平替”**：
   - 严禁大篇幅堆砌晦涩文言文，而是提炼历史人物困境内核，翻译为现代年轻人高频痛点词（熬的夜、咽的话、没赢的仗、房贷、失业、考研受挫、35岁职场危机）。

3. **强烈的古今视听反差（Hook）**：
   - **视觉**：传统古代汉服长袍 vs 昏暗庄重的现代/复古演播殿堂与 1950 年代立式铬色麦克风。
   - **听觉**：叙事国风说唱（Rap/独白）+ 空灵大气的女高音副歌/史诗群像合唱（Chorus）。

4. **评论区的“树洞效应”与长尾共鸣**：
   - 副歌成为情绪宣泄容器（“我是过来人，一千年前揣着跟你一样的心……” / “前面有人为你留了火，后头有整座青史替你作底气！”），引导观众自发倾诉与转发。

## 🎬 创作标准落地交付规范

### 1. 视频文案与互动设计规范
- **标题命名格式**：`原唱：[历史人物1]、[历史人物2]、[历史人物3]……`
- **正文结构**：`[人物最狼狈的历史真相] ➔ [对应现代受众的委屈与不甘] ➔ [释怀金句与精神兜底]`
- **置顶评论引导**：“哪位姐姐/先贤的那句话，戳中了你最近最难迈过的坎？”

### 2. 歌词编排规范
- **BPM**：80~85 BPM（最契合叙事说唱与情绪共鸣）。
- **结构标签**：`[Intro] ➔ [Verse 1 人物独白 Flow] ➔ [Verse 2] ➔ [Chorus 空灵全员合唱 Hook] ➔ [Verse 3] ➔ [Verse 4] ➔ [Verse 5] ➔ [Chorus 史诗高潮 Climax] ➔ [Outro 留白金句]`。

### 3. AI 音乐生成提示词规范 (Suno / Udio)
- **Style of Music 模板**：
  `Chinese traditional conscious hip hop, [vocal type: female/male choir], melancholy Guzheng and Xiao flute intro, transitioning into an epic cinematic choir, punchy 808 sub-bass, sorrowful strings, emotional storytelling, 82-84 bpm`

### 4. AI 视频分镜提示词（电影级 5 段式标准）
适配即梦 (Seedance)、可灵 (Kling)、Wan 2.1 等模型：
- **【核心主题】**：写实古典电影质感 / 古今对话群像 / 暖调油画光影 / 殿堂演播室
- **【主体与场景设定】**：人物面部微瑕真实风霜（非美颜假人）、精确朝代服饰纹理、复古金属立式麦克风
- **【氛围与摄影器材锚定】**：阿莱 Alexa 35 / 库克定焦 / 伦勃朗光柱 / 35mm 胶片颗粒感
- **【运镜与动作规则】**：慢速推镜头 (Slow Dolly-in) / 弧形环绕 (Orbital tracking) / 呼吸感手持 / 严禁剧烈晃动
- **【分时段分镜切片】**：0-3s 建立、3-8s 表情与唱词开合、8-12s 升华与大景深
- **【反向提示词 (Negative Prompt)】**：`blurry, glossy 3D render, plastic smooth face, anime, modern clothing, extra fingers, rapid shaking`
